# Корневой сертификат для GigaChat

API GigaChat (Сбер) использует сертификат НУЦ Минцифры («Russian Trusted Root CA»), которого нет в стандартном наборе Node.js.
Чтобы помощник работал через GigaChat, положите сюда файл **`russian_trusted_root_ca.pem`**:

1. Скачайте «Корневой сертификат» с https://www.gosuslugi.ru/crt (Windows/«Другие ОС» → файл `russian_trusted_root_ca_pem.crt`).
2. Переименуйте в `russian_trusted_root_ca.pem` и положите в эту папку, закоммитьте (это публичный сертификат, не секрет).

Контейнер подключает его через `NODE_EXTRA_CA_CERTS`. Проверку TLS мы **не отключаем**. Без файла помощник автоматически работает в режиме поиска по Положению.
