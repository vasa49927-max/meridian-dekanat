# Корневые сертификаты для GigaChat

API GigaChat (Сбер) использует сертификаты НУЦ Минцифры («Russian Trusted Root CA»), которых нет в стандартном наборе Node.js.
Положите сюда файлы с https://www.gosuslugi.ru/crt — подойдут как есть (`.cer` в двоичном виде или `.pem`):

- `Russian_Trusted_Root_CA.cer` — корневой (обязателен)
- `Russian_Trusted_Sub_CA.cer`, `Russian_Trusted_Sub_CA_2024.cer` — промежуточные (не помешают)

При старте сервер добавляет их к стандартным доверенным сертификатам (`src/server/certs.ts`). Проверку TLS мы **не отключаем**.
Это публичные сертификаты, не секрет — их можно коммитить. Без них помощник работает в режиме поиска по Положению.
