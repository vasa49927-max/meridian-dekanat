# «Меридиан» — цифровой деканат будущего

> **Концепт для конкурса МГИМО по ИИ. Не является официальным сервисом МГИМО.** Все люди и данные вымышлены.

Личный кабинет студента, в котором учёба, документы и связь с деканатом собраны в одном месте и удобно работают с телефона. Код написан ИИ-ассистентом (Claude) под руководством капитана команды; весь процесс — в [`docs/PROCESS_LOG.md`](docs/PROCESS_LOG.md).

**Демо:** _ссылка появится после деплоя на Amvera_ · **Тестовые аккаунты:** [`docs/TEST_ACCOUNTS.md`](docs/TEST_ACCOUNTS.md)

## Что внутри
| Раздел | Что умеет |
|---|---|
| **Сегодня** | следующая пара с живым отсчётом и подсказкой «как дойти», переносы «было → стало», сроки, статусы заявок, риски по учёбе, объявления |
| **Расписание** | день/неделя, переносы и отмены подсвечены и продублированы уведомлениями, языковые подгруппы, день ВУЦ, экспорт в календарь `.ics` |
| **Успеваемость** | баллы БРС по контрольным точкам, «сколько до автомата», риски, калькулятор «что, если», зачётка прошлых семестров |
| **Заявки и справки** | каталог из 9 видов, форма за 1 экран с данными из профиля, трекер статусов (подана → в работе → готова → выдана / нужно дополнить / отклонена), электронная справка с **QR-проверкой подлинности** |
| **Уведомления** | лента с фильтрами, важные, прочитано/не прочитано, счётчик, «созревающие» напоминания о сроках |
| **ИИ-помощник** | отвечает по вымышленному Положению (со ссылками на пункты) и данным самого студента, умеет заполнить заявку; GigaChat или офлайн-режим |
| **Запись к методисту** | слоты по 20 минут вместо живой очереди |
| **Поиск Ctrl+K** | разделы, дисциплины, заявки, быстрые действия |
| **Кабинет деканата** | очередь заявок с фильтрами → смена статуса → студент сразу получает уведомление и справку с QR; адресные объявления; переносы пар; приём; сброс демо-данных |
| **PWA** | установка на телефон, офлайн-экран, светлая/тёмная тема |

## Стек
Next.js 16 (App Router, Server Components/Actions) · TypeScript · Tailwind CSS 4 · компоненты в духе shadcn/ui · lucide · Drizzle ORM + PostgreSQL 16 · zod · argon2id · Playwright + Vitest · Docker. Обоснования — [`docs/DECISIONS.md`](docs/DECISIONS.md).

## Быстрый старт
```bash
cp .env.example .env            # заполнить DATABASE_URL
npm install
npm run db:up                   # локальный PostgreSQL (или docker compose up db)
npm run db:migrate && npm run db:seed
npm run dev                     # http://localhost:3000
```
Всё в Docker: `docker compose up --build`.

## Проверки
```bash
npm run typecheck && npm run lint
npm test                        # unit + интеграционные тесты изоляции на уровне БД (19)
npm run test:e2e                # Playwright: 35 сценариев, десктоп и 360 px
npm run build && npm run check:bundle   # секретов в клиентской сборке нет
```
Lighthouse (мобильный профиль): Performance 90–98, Accessibility 100 — [`docs/lighthouse/summary.json`](docs/lighthouse/summary.json).
