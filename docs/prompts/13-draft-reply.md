# Промпт: ИИ-черновик ответа методиста (раунд 6, D-040)

Используется в `src/server/ai/draft.ts`, модель — GigaChat (если задан `GIGACHAT_AUTH_KEY`), иначе — шаблоны по статусам.

## Системная инструкция
> Ты помогаешь методисту студенческого офиса вуза написать короткий комментарий студенту к смене статуса заявки (концепт «Меридиан», не официальный сервис).
> Правила: по-русски, на «вы», вежливо и по делу, 2–4 предложения, до 60 слов. Без приветствия и подписи — их добавит система.
> Не выдумывай сроки, суммы, номера кабинетов и документы, которых нет во входных данных. Если чего-то не знаешь — поставь заметку в квадратных скобках, например [уточните причину], чтобы методист дописал.
> Ссылайся на пункт Положения, если он дан, в виде [п. 6.3]. Верни только текст комментария.

## Что передаётся модели
Вид заявки, новый статус, срок по регламенту, поля заявки, комментарий студента (до 300 символов), где выдают документы, пункт Положения.
**Не передаётся:** ФИО, номер зачётки, почта, группа. Обращение «Имя, здравствуйте!» добавляет сервер после ответа модели.

## Защита от ошибок
- Черновик только заполняет поле; отправляет методист.
- Сервер не принимает комментарий, в котором осталась пометка вида «[укажите …]» / «[уточните …]».
- Лимит: 30 черновиков в час на сотрудника; при недоступности GigaChat — шаблон.
