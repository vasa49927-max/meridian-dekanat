# Ручные шаги капитана (пошагово)

Секреты (ключи, пароли) **никогда не присылай в чат** — только вписываешь в настройки хостинга.

## 1. GigaChat API (ключ для ИИ-помощника) — ~10 минут
1. Открой https://developers.sber.ru/studio и войди через Сбер ID.
2. «Создать проект» → выбери **GigaChat API** → тип «Для физических лиц» (бесплатный Freemium-лимит).
3. В проекте открой «Настройки API» → «Получить ключ». Скопируй **Authorization Key** (длинная строка base64) и **Scope** (обычно `GIGACHAT_API_PERS`).
4. Сохрани их в заметке/менеджере паролей. Понадобятся на шаге деплоя (переменные `GIGACHAT_AUTH_KEY`, `GIGACHAT_SCOPE`).
5. Напиши мне в чат только: «ключ GigaChat получен».

## 2. GitHub — ~10 минут
1. Зарегистрируйся на https://github.com (если нет аккаунта).
2. Установи **GitHub Desktop** (https://desktop.github.com) и войди в него своим аккаунтом.
3. Пока всё — репозиторий опубликуем из папки `Z:\Desktop\MGIMOAI\dekanat` на контрольной точке (б): я положу туда проект вместе с историей коммитов, тебе останется «Add local repository» → «Publish repository» (галочку «Keep this code private» снять).

## 3. Amvera — ~10 минут
1. Зарегистрируйся на https://amvera.ru (почта или телефон).
2. Пополни баланс на **700 ₽** (хватит до 28.11 с запасом: приложение 490 ₽/30 дн + база 290 ₽/30 дн, оплата поминутная).
3. Больше ничего не создавай — пошаговую инструкцию по базе и приложению пришлю на контрольной точке (б).

## 4. Опрос однокурсников
Анкета — `docs/manual/SURVEY.md`. Создай в Яндекс Формах, разошли, через 1–2 дня пришли выгрузку .xlsx.

## 5. Где честно подключить другие ИИ-инструменты (для критерия 2)
| Инструмент | Для чего | Что сохранить для PDF |
|---|---|---|
| **Шедеврум** или **Kandinsky** (Сбер) | иллюстрация для экрана входа и пустых состояний (стиль задам промптом) | промпт + 2–3 варианта, какой выбрали |
| **GigaChat** (веб) | «второе мнение»: прогнать тексты интерфейса и анкету, попросить критику | скрин диалога |
| **Яндекс SpeechKit / Алиса** или свой голос | озвучка видео по моему сценарию | что использовал |
| **Нейросеть для анализа опроса** (GigaChat/YandexGPT) | сводка открытых ответов анкеты | промпт + сводка |
