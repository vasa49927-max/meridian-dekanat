# Деплой на Amvera — пошагово для капитана (~30 минут)

Что будет в конце: ссылка вида `https://meridian-<ваш-логин>.amvera.io`, которая открывается из России без VPN.
Секреты (пароль БД, ключ GigaChat) вписываете **только** в настройках Amvera — не в чат и не в файлы.

## Шаг 0. Подготовка (5 минут)
1. Распакуйте `Z:\Desktop\MGIMOAI\dekanat\meridian-repo.zip` в папку `Z:\Desktop\MGIMOAI\dekanat\meridian` (внутри будет скрытая папка `.git` — это история коммитов, её не трогаем).
2. **Сертификат для GigaChat:** откройте https://www.gosuslugi.ru/crt → «Корневой сертификат» → скачайте вариант для «Другие ОС / Linux» (`russian_trusted_root_ca_pem.crt`). Переименуйте в `russian_trusted_root_ca.pem` и положите в `meridian\certs\`.

## Шаг 1. GitHub (5 минут)
1. GitHub Desktop → File → **Add local repository** → выберите папку `meridian`.
2. Вкладка Changes: появится `certs/russian_trusted_root_ca.pem` → внизу Summary: «Сертификат для GigaChat» → **Commit to main**.
3. **Publish repository** → имя `meridian-dekanat` → **снимите галочку «Keep this code private»** → Publish.
4. Пришлите мне ссылку на репозиторий.

## Шаг 2. База данных в Amvera (5 минут)
1. amvera.ru → «Проекты» → **Создать** → тип **PostgreSQL** → название `meridian-db` → тариф **«Начальный»**.
2. Параметры: имя БД `meridian`, пользователь `meridian`, пароль — сгенерируйте длинный (сохраните у себя). Остальное — по умолчанию.
3. После создания откройте проект → вкладка «Инфо»: найдите **внутреннее имя хоста** вида `amvera-<логин>-cnpg-meridian-db-rw`. Скопируйте.

## Шаг 3. Приложение (10 минут)
1. «Проекты» → **Создать** → тип **Приложение** → название `meridian` → тариф **«Начальный Плюс»** (1 ГБ ОЗУ).
2. Способ загрузки — **через GitHub**: вкладка «Репозиторий» → GitHub → ветка `main` → придумайте секрет → скопируйте адрес вебхука.
   В GitHub: репозиторий → Settings → Webhooks → Add webhook → Payload URL = адрес из Amvera, Content type = `application/json`, Secret = ваш секрет, событие **Just the push event** → Add.
3. Вкладка **«Переменные»** → «Добавить» (для паролей — тип **«Секрет»**):

| Название | Значение | Тип |
|---|---|---|
| `DATABASE_URL` | `postgresql://meridian:<пароль БД>@<хост из шага 2>:5432/meridian` | секрет |
| `GIGACHAT_AUTH_KEY` | Authorization Key из кабинета GigaChat | секрет |
| `GIGACHAT_SCOPE` | `GIGACHAT_API_PERS` | переменная |
| `APP_URL` | адрес из шага 4 (можно вписать после) | переменная |
| `TRUSTED_PROXY_HOPS` | `1` | переменная |
| `DEMO_RESET_ENABLED` | `true` | переменная |

4. Вкладка «Настройки» → **доменное имя** → включите бесплатный домен Amvera (HTTPS). Скопируйте адрес, впишите его в `APP_URL`.
5. Запустите сборку («Собрать» / или сделайте любой коммит в GitHub). Сборка занимает 3–6 минут.

## Шаг 4. Проверка (5 минут)
1. Вкладка «Логи приложения»: должны быть строки `[startup] пустая база — создаём демо-данные` и `[startup] готово`.
2. Откройте `https://…/api/health` → `{"ok":true}`.
3. **С телефона на мобильном интернете без VPN:** откройте ссылку, войдите как `sokolova` / `Demo-2026-anna`, пройдите: Сегодня → Расписание → Заявки → Помощник («справка для военкомата»). Пришлите 2–3 скриншота — они пойдут в PDF.

## Если что-то пошло не так
| Симптом | Что сделать |
|---|---|
| Сборка падает с нехваткой памяти | Временно поднимите тариф до «Стандартный» на время сборки, потом верните |
| В логах `ECONNREFUSED` / `password authentication failed` | Проверьте `DATABASE_URL`: хост из «Инфо» БД, пароль, порт 5432 |
| Помощник пишет «Ответ собран из Положения без нейросети» | Проверьте `GIGACHAT_AUTH_KEY` и что файл сертификата в `certs/` закоммичен; пришлите строку `[assistant] …` из логов |
| Изменили переменные — ничего не поменялось | Перезапустите приложение (переменные применяются только при перезапуске) |
