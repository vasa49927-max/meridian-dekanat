# Языки интерфейса (i18n)

Русский — основной язык, английский, китайский и французский — для иностранных студентов (D-035).
Язык хранится в cookie `lang`, переключатель — в шапке, на странице входа, в «Ещё» и профиле.

## Как устроено
- `src/i18n/config.ts` — список языков.
- `src/i18n/dict/<язык>/<раздел>.ts` — словари. **Русский — источник истины**: файлы `en/zh/fr` типизированы `Shape<typeof ru>`, и TypeScript не даст пропустить ключ.
- `src/i18n/data.ts` — переводы данных из БД (названия предметов, корпусов, видов заявок…), ключ — русский текст.
- `src/i18n/brs.ts` — тексты БРС (`planText`, `riskText`).
- `fmtFor(locale)` в `src/lib/time.ts` — даты на нужном языке. Русский `fmt` остаётся для текстов, которые сохраняются в БД (уведомления, .ics).

## Как использовать
Серверный компонент или Server Action:
```ts
const { t, tn, tr, name, f } = await getI18n(); // import { getI18n } from "@/i18n/server"
t("today.next.title")                      // строка
t("today.greeting", { name: "Анна" })      // подстановка {name}
tn("schedule.lessons", 3)                  // множественное число: { one, few, many, other } → «3 пары»
tr("subjects", d.name)                     // данные из БД: перевод или оригинал
name(teacherLast)                          // имена — латиницей в нерусских интерфейсах
f.dayMonth(date), f.shortDay(date), f.rel(date, at), f.near(date, at)
```
Клиентский компонент: `const { t, tn, tr, name, f } = useI18n();` (`import { useI18n } from "@/i18n/client"`).

## Правила
1. Русский текст в словаре — **ровно тот, что был в коде** (на нём держатся e2e-тесты).
2. Ключи — по смыслу, camelCase, сгруппированы по разделам страницы.
3. Множественное число — только через `tn` и объект форм (`ru`: one/few/many/other, `en/fr`: one/other, `zh`: other).
4. Части фразы с выделением (`<b>`) — отдельными ключами или подстановкой, без HTML в словаре.
5. Тексты, которые пишут люди (объявления, комментарии деканата, тексты уведомлений из БД), не переводим.
6. Кабинет сотрудника деканата — только на русском (сотрудники русскоязычные), общие компоненты переводятся.
7. Китайский и французский перевод — машинный (ИИ), перед реальным запуском нужна вычитка носителем.
