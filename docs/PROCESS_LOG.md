## Этап 1. Каркас репозитория и правила для ИИ-агентов · 06.11.2026
- **Задача:** до первой строки кода написать «конституцию» проекта для любых ИИ-агентов.
- **Что сделал ИИ:** `AGENTS.md` (стек, структура, 9 правил безопасности, стиль кода, команды, Definition of Done), `CLAUDE.md` (импортирует AGENTS.md + правила работы с субагентами и ошибками ИИ), `docs/DECISIONS.md` (D-001…D-009), `.gitignore`, копия ТЗ.
