# PRD — «Меридиан»: цифровой деканат будущего

> Статус: v1.0 (07.11.2026). Исследование — `docs/research/RESEARCH.md`, опрос однокурсников — `docs/research/SURVEY_RESULTS.md`.

## 1. Проблема
Учебная жизнь студента МГИМО разбросана: расписание — на сайте и в чате группы, баллы — в отдельной системе, справки — через очередь и личный визит, объявления — в Telegram-чатах и почте. Отсюда пять конкретных болей (номера — из исследования):
1. **«Я узнал о переносе, когда пришёл к закрытой аудитории»** — изменения не доходят адресно (боли 1, 2, 6).
2. **«Я не понимаю, сколько мне нужно до автомата»** — БРС непрозрачна, нет сценария «что, если» (пробел исследования, проверяем опросом).
3. **«Справка — это день жизни»** — заявка, очередь, личный визит, ожидание 1–3 дня (боль 8; кейс МИСИС: 3 дня → 5 минут).
4. **«Каждый отдел отсылает к другому»** — непонятно, кого и о чём спрашивать (боль 9).
5. **«С телефона неудобно»** — порталы делали под десктоп, медленные, с короткой сессией (боли 3, 5, 10).

**Ценность:** один экран, который отвечает на вопрос «что мне сегодня нужно знать и сделать?» — и всё остальное в одно-два касания.

## 2. Голос студентов
- Исследование открытых источников — 10 болей (см. RESEARCH.md §2).
- Опрос однокурсников (11 ответов, 2 курс, 07.11) — `docs/research/SURVEY_RESULTS.md`:
  - **11/11** узнают о переносах только из чата группы; **6/11** пропускали важное объявление;
  - понятность рейтинга и «автомата» — **3,2 из 5**;
  - **4 из 9** ждали справку 3 дня и дольше; **73%** заходят с телефона; **73%** готовы спросить ИИ-помощника;
  - утром нужно: расписание с аудиториями (9/11), рейтинг по сегодняшним предметам (3/11), важные объявления (3/11).

## 4. Ключевые сценарии (end-to-end)
1. **Утро.** Анна открывает «Сегодня»: следующая пара с обратным отсчётом, аудитория и корпус; жёлтая плашка «перенос: было → стало»; сроки; статусы заявок.
2. **Справка за 1 минуту.** Тимур: «Заявки» → «Справка для военкомата» → форма предзаполнена из профиля → 1 поле «куда» → «Отправить». Статус: подана → в работе → готова. Готовую справку открывает как электронный документ с QR-кодом; военкомат сканирует QR → публичная страница «Документ подлинный».
3. **Деканат.** Ирина видит очередь с фильтрами (тип, статус, курс, просрочено) → берёт в работу → «готова» с комментарием. Студент сразу видит новый статус и уведомление.
4. **Перенос пары.** Ирина вносит перенос → система находит затронутые группы → студенты получают уведомление, в расписании пара подсвечена «было → стало».
5. **Как дела с учёбой.** Анна видит средний балл, риски, «сколько баллов не хватает до автомата» и двигает ползунок «что, если».
6. **Помощник.** Мэй спрашивает «какую справку взять для визы?» → помощник отвечает по положению со ссылкой на пункт и предлагает «Заполнить заявку» — форма открывается предзаполненной.
7. **Изоляция.** Студент B, подставив id заявки студента A в адрес, получает 404.

## 5. Разделы и обоснование
| Раздел | Почему | Боль |
|---|---|---|
| Сегодня (главный) | один ответ на «что важно сейчас» | 1, 5 |
| Расписание (сегодня/неделя, .ics) | переносы «было → стало», подписка в календарь телефона | 1, 2 |
| Успеваемость + «что, если» | прозрачная БРС, путь к автомату | 2 |
| Заявки и справки + QR | без очереди и бумаги, проверяемый документ | 3 |
| Уведомления (важное/учёба/деканат/события) | приоритет, прочитано/нет, нельзя отключить «важное» | 1, 4 |
| Кабинет деканата | замыкает цикл «подал → обработали → увидел» | 3, 4 |

## 6. Смелые идеи (выбор на КТ (а))
**Предлагаем сделать качественно (4):**
1. **Главный экран «Сегодня»** — следующая пара с отсчётом и маршрутом, переносы, сроки, заявки, объявления (S).
2. **ИИ-помощник деканата на GigaChat** — ответы по вымышленному «Положению» со ссылкой на пункт и по данным самого студента; кнопка «заполнить заявку за меня»; без ключа — режим поиска по положению (M).
3. **Калькулятор «что, если» для БРС** — сколько баллов до автомата/«отлично», ползунок по оставшимся контрольным (S).
4. **Электронная запись к методисту** — слоты, тема визита, напоминание, отмена; у деканата — расписание приёма (S–M).

**Поддерживающие (малой ценой):** командная палитра ⌘K / поиск по всему кабинету; тёмная тема; PWA (установка на телефон, офлайн-экран); статус «на доработку» как в Госуслугах; справка на английском для посольства; день ВУЦ в расписании.

**Отложено (в «каким деканат может стать» в PDF):** языковой паспорт, режим «Еду за рубеж», клубы и события, кампус-навигатор с картой.

## 7. Вне рамок
Интеграция с реальными системами МГИМО; реальные ПД; оплата; LMS-задания (только как сроки в ленте).

## 8. Метрики успеха прототипа
- Сценарии 1–7 проходятся жюри без инструкции ≤ 2 касаний до цели с главного экрана.
- Lighthouse mobile ≥ 90 (Performance, Accessibility).
- 0 найденных IDOR у независимого аудитора; e2e-тесты изоляции зелёные.
