# Опрос однокурсников: итоги

**Кто проводил:** капитан (Родион), Яндекс Формы, анкета `docs/manual/SURVEY.md`.
**Когда:** 7 ноября 2026 года. **Ответов:** 11, все студенты 2-го курса бакалавриата. Опрос анонимный.
**Как анализировали:** выгрузку .xlsx посчитал Claude (pandas/openpyxl), свободные ответы сгруппировал по темам вручную и с помощью ИИ, а капитан проверил группировку.
**Ограничения:** выборка маленькая и только из одного курса, поэтому это сигнал для дизайна, а не статистика.

## Цифры
| Вопрос | Результат |
|---|---|
| Где узнаёшь о переносе/отмене пары? | **11 из 11 — из чата группы или от старосты.** Официального канала нет совсем |
| Пропускал(а) важное объявление, потому что оно было «не там» | 0 раз — 5 человек; 1–2 раза — 4; 3–5 раз — 2. **Больше половины (6 из 11) хотя бы раз пропускали** |
| Насколько понятно, как дела с рейтингом и что нужно для «автомата» (1–5) | **В среднем 3,2.** Ответили «1–2» — 4 человека (36%), «5» — только 3 |
| Какие справки оформляли за год | об обучении — 6, для военкомата — 4, для визы — 1, о стипендии — 0, никаких — 3 |
| Сколько ждали справку | в тот же день — 1, 1–2 дня — 4, 3–5 дней — 2, **больше недели — 2**, не заказывали — 2. **4 из 9 ждали 3 дня и дольше** |
| С чего заходишь в учебные сервисы | **с телефона — 8 (73%)**, с ноутбука — 2, поровну — 1 |
| Спрашивал(а) бы ИИ-помощника о правилах и своих данных | да — 5, скорее да — 3, скорее нет — 2, нет — 1. **73% — «да» или «скорее да»** |

## Что раздражает (свободные ответы, сгруппированы)
- **Долгая обратная связь, деканат «игнорит»** (4): «слишком долгая обратная связь», «до деканата невозможно дописаться, приходится всегда лично туда ходить», «они игнорят», «задержка информации».
- **Ожидание справок и бюрократия** (3): «долгота ожидания справки, непонятность», «бюрократия», «заверка справок о больничном».
- **Неудобно с телефона** (1): «ЛКС очень неудобно открывать с телефона, когда нужно быстро что-то посмотреть».
- Претензий нет — 3.

## Что должно быть на экране, который открываешь утром
- **Расписание на день — 9 из 11.** Отдельно просили: «с кабинетами и преподавателями», «сколько у меня пар и где».
- **Рейтинг по предметам — 3**, в том числе «рейтинг по предметам, которые сегодня в расписании».
- **Важные объявления и анонсы — 3**, мероприятия студсовета — 1.
- Дата (число, месяц) — 1.

## Что мы изменили по итогам
| Вывод из опроса | Решение в «Меридиане» |
|---|---|
| О переносах узнают только из чатов, больше половины пропускали важное | Переносы и отмены на главном экране и в расписании, у каждого изменения уведомление. После ручного теста капитана формат «было → стало» переделан на понятный без зачёркиваний |
| Расписание — главное утром, нужны аудитория и преподаватель | В карточке «Следующая пара» крупно предмет, день, время начала и аудитория |
| Рейтинг понятен на 3,2 из 5 | Раздел «Успеваемость» переработан вокруг вопроса «что мне сделать». На «Сегодня» добавлен блок **«Баллы по сегодняшним предметам»** — идея одного из респондентов |
| Справки ждут днями, в деканат «невозможно дописаться» | Онлайн-заявки со сроком и трекером, ответ деканату с **вложениями** прямо в заявке, запись к методисту вместо очереди |
| 73% заходят с телефона | Приоритет 360 px: нижнее меню, проверка горизонтального скролла в каждом тесте |
| 73% готовы спросить ИИ-помощника | Помощник с опорой на Положение и данные студента. Он честно говорит «не знаю» и никогда не отправляет заявку сам — это для тех 3 из 11, кто ИИ не доверяет |
