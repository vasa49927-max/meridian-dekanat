# Аудит удобства и «Посольство 2.0» (раунд 7, 11.11.2026)

Полная версия с графиком и скриншотами — документ «„Меридиан“: аудит удобства и обновление дизайна» (Claude Docs). Здесь — короткая копия для репозитория.

**Итог.** На телефоне частые задачи студента стали быстрее на 19% (сумма по 13 задачам 85,6 → 69,2 с по модели KLM), самые долгие — в 1,3–2 раза. Исправлено 10 проблем удобства, интерфейс переведён на «Посольство 2.0». Доступность (axe, WCAG 2 A/AA) — 0 нарушений, 50 unit + 71 e2e зелёные.

**Метод.** `scripts/ux-paths.mjs` проходит задачи реальными кликами в браузере (Playwright) на 1440 и 360 px. Время — KLM (Card, Moran, Newell): решение 1,35 с, навести 1,1 с, нажать 0,2 с, экран прокрутки ≈ 1 с, плюс 1,35 с найти результат глазами. Это оценка для опытного пользователя без ошибок; сравнение «до/после» корректно, абсолютные секунды — ориентир.

## Что исправлено
1. Быстрые действия на главной: справка, неделя, запись к методисту, маршрут; на телефоне — статус активной заявки (D-044).
2. Язык интерфейса — в «Ещё» на телефоне.
3. Меню в три группы: «Учёба / Деканат / Моё»; у сотрудника — «Работа / Аналитика / Сервис» (D-045).
4. Очередь деканата: сначала требующие действия, «Готовы к выдаче» — в конце (D-047).
5. Порядок блоков главной на телефоне: пара → быстрые действия → переносы → пары дня → помощник → сроки → заявки → баллы → объявления.
6. Компактная шапка «Расписания» на телефоне (первая пара выше на 65 px).
7. «Ещё» подсвечивается на «Портфолио», «Оценке курсов», «Как пройти».
8. Ссылка «Неделя» ведёт на вид «Неделя».
9. Разметка для экранных читалок: плашка преподавателя, фильтр «Мои», таблица методистов.
10. Подсказка первого входа описывает новую главную (4 языка).

Попутно найден и исправлен дефект: совпадение случайных номеров заявок (≈ 5% сбросов демо-данных) и неработающий повтор при подаче (PROCESS_LOG, ошибка ИИ №36).
