## Маршрут для жюри за 5 минут
1. **Анна (`sokolova`), телефон или компьютер.** «Сегодня»: следующая пара с отсчётом и «Как пройти», переносы недели, быстрые действия, прогноз стипендии.
2. **«Успеваемость»** → карточка «Статистика»: что делать, чтобы закрыть предмет; «Все работы и калькулятор итога» — «что, если». Вкладка «Курсы по выбору» — запишитесь на курс.
3. **«Заявки» → «Новая заявка» → «Справка об обучении»**: данные подставлены из профиля, отправка за одно касание.
4. **Сотрудник (`belova`)**: очередь заявок → заявка Анны → «Черновик ИИ» → «Готова». Электронная справка с QR создаётся сама.
5. **Снова Анна**: уведомление «Справка об обучении: готова» → заявка → QR-код → страница проверки подлинности (открывается без входа).
6. **Безопасность**: под Анной откройте чужую заявку по прямой ссылке — 404. Под студентом откройте `/staff` — вернёт в кабинет.
7. **Ещё**: «Помощник» («какую справку взять для визы?» → кнопка «Заполнить заявку»), `lin` — чек-лист первокурсника и Одинцово, переключатель языка (EN/中文/FR) и тёмная тема.

Демо-данные обновляются автоматически каждую ночь в 4:00 МСК (и вручную: `belova` → «Демо-данные»).
