# Соответствие ТЗ конкурса

Каждое требование ТЗ «Цифровой деканат будущего» → где оно сделано → как проверить за минуту. Аккаунты — в [`TEST_ACCOUNTS.md`](TEST_ACCOUNTS.md), сайт — https://meridian-iwkag.msk1.amvera.tech

## Обязательное ядро
| Требование | Где сделано | Как проверить |
|---|---|---|
| Вход по логину и паролю | `src/app/(auth)/login`, `src/server/auth/*` (argon2id, сессии в БД) | Страница входа → кнопка `sokolova` → «Войти» |
| Профиль: ФИО, факультет, направление, курс, группа | `/profile` | Аватар внизу меню или «Ещё» → «Профиль» |
| Расписание на сегодня и неделю, аудитория, преподаватель | `/`, `/schedule` (День / Неделя / Сессия) | «Сегодня» → карточка пары; «Расписание» → «Неделя» |
| Заметные изменения и переносы | баннер на «Сегодня», метки «Отмена / Перенос / Новая аудитория», уведомления | У Анны на неделе 2 изменения |
| Оценки и зачёты по дисциплинам | `/grades`, зачётка `?tab=record` | «Успеваемость» |
| Сессия | `/schedule?view=session` | «Расписание» → «Сессия» |
| «Как у меня дела с учёбой» | карточка на «Сегодня», план по каждому предмету, «С чего начать», прогноз стипендии | «Сегодня» → «Как дела с учёбой» |
| Заказ справки / подача заявления онлайн | `/requests/new` — 10 видов | «Заявки» → «Новая заявка» |
| Статус заявки | `/requests/[id]` — история статусов, кто ведёт | Под `belova` смените статус → под Анной откройте заявку |
| Новости и объявления деканата | `/notifications`, «Объявления» на главной | «Уведомления» → «Объявления» |
| Напоминания о дедлайнах и изменениях | «Ближайшие сроки», уведомления о переносах, push, утренняя сводка | «Сегодня» → «Ближайшие сроки» |

## Требования к прототипу
| Требование | Где сделано | Как проверить |
|---|---|---|
| Работающий прототип, не макет | Next.js + PostgreSQL на Amvera | Пройти маршрут из `TEST_ACCOUNTS.md` |
| Стек адекватный и масштабируемый | stateless-приложение, сессии и лимиты в БД — можно запускать несколько копий; нагрузочный тест | `docs/ARCHITECTURE.md`, раздел «Масштабирование» |
| Код пишут ИИ-ассистенты | Claude (Cowork) + субагенты, правила в `AGENTS.md`, `CLAUDE.md` | `docs/PROCESS_LOG.md`, `docs/prompts/` |
| Мобильная версия от 360 px | все страницы; e2e-проверка ширины 360 px | `tests/e2e/mobile.spec.ts`; открыть сайт с телефона |
| Только вымышленные данные | `src/server/seed/data.ts`, вымышленное «Положение» | Пометка на каждой странице; люди и номера придуманы |
| Не выдавать за официальный сервис | дисклеймер на входе и в подвале каждой страницы, на печати резюме | Любая страница, внизу |
| Без логотипа вуза | свой логотип «Меридиан» (глобус с меридианами) | `src/components/logo.tsx` |
| Сторонний код — разрешающие лицензии | MIT / Apache-2.0 / ISC / OFL | `docs/LICENSES.md` |
| Студент видит только свои данные | DAL фильтрует по сессии; чужой объект → 404 | Под `galiev` открыть ссылку на заявку Анны → 404; `tests/e2e/isolation.spec.ts`, `tests/unit/dal-isolation.test.ts` |
| Пароли не в открытом виде | argon2id-хэш | `docs/SECURITY.md` |
| Ключи не в коде и не в браузере | переменные окружения Amvera, `src/server/env.ts`, `scripts/check-bundle.mjs` | `npm run build && npm run check:bundle` |
| Открывается из России без VPN до 28.11 | хостинг Amvera (РФ), без внешних CDN и шрифтов | Открыть ссылку без VPN |
| Тестовые аккаунты: ≥ 2 студента + сотрудник | 3 студента с разными данными + сотрудник | Кнопки на странице входа |

## Сверх ядра (смелые идеи)
ИИ-помощник по Положению с заполнением заявки · электронная справка с QR-проверкой · ИИ-черновик ответа методиста · панель руководителя и раннее предупреждение о рисках · курсы по выбору с листом ожидания · прогноз стипендии · анонимный опрос о курсах · портфолио и резюме · схема «Как пройти» · подписка на расписание в календаре, push-уведомления и чат-бот MAX (готов к подключению) · 4 языка · тёмная тема · установка на телефон (PWA).
