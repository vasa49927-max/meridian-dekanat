# Журнал решений (ADR-lite)

Формат: **D-NNN — решение** · кто решил · почему · альтернативы.
«Капитан» — решение Родиона; «ИИ» — решение Claude по умолчанию (Родион может пересмотреть).

### D-001 — Хостинг: Amvera · Капитан (06.11)
Российский PaaS: деплой из Dockerfile по git push/вебхуку GitHub, managed PostgreSQL (CloudNativePG) в том же кабинете, HTTPS-домен, оплата в рублях.
Тарифы (docs.amvera.ru/general/price.html, 06.11.2026): приложение «Начальный Плюс» 0,5 CPU / 1 ГБ — 490 ₽/30 дн; PostgreSQL «Начальный» 0,25 CPU / 500 МБ — 290 ₽/30 дн. Посекундная оплата → до 28.11 ≈ 600 ₽.
Альтернативы: Timeweb Cloud (дороже, больше ручной настройки), Yandex Cloud (грант, но сложная настройка IAM/сетей/реестра). Отклонены: Vercel/Netlify/Render — нестабильно открываются в РФ без VPN.

### D-002 — ИИ-помощник в кабинете: GigaChat API · Капитан (06.11)
Ключ — только в переменной окружения сервера. Вызов — только из route handler `/api/assistant`. Нет ключа → помощник показывает аккуратное «выключено» и работает в режиме поиска по положению без LLM.

### D-005 — Стек: Next.js 16 (App Router) + TS + Tailwind v4 + shadcn/ui + Prisma 7 + PostgreSQL 16 · ИИ (06.11)
Совпадает с дефолтом ТЗ команды. Один язык (TS) на фронте и бэке — ИИ-агентам проще держать контекст; Server Components уменьшают JS на клиенте (Lighthouse). Prisma 7 — стабильная ветка (8.x на 06.11 ещё RC), работает через драйвер `pg` без бинарного движка → меньше образ.
Масштабирование: сервер без состояния (сессии и лимиты попыток — в БД), можно поднять N реплик за балансировщиком; индексы на всех внешних ключах и полях фильтрации; курсорная пагинация лент.

### D-006 — Собственные сессии вместо NextAuth/Auth.js · ИИ (06.11)
Нужен только вход по логину/паролю. Своя реализация — ~150 строк, полностью прозрачна для жюри и аудитора: токен 32 байта → в cookie, SHA-256 → в БД, срок 7 дней со скользящим продлением, logout удаляет запись. Меньше «магии» и зависимостей.

### D-007 — argon2id через `@node-rs/argon2` · ИИ (06.11)
Предсобранные бинарники (без node-gyp) → надёжная сборка в Docker на Amvera. Параметры OWASP: m=19 МиБ, t=2, p=1.

### D-008 — Локальная БД без Docker · ИИ (06.11)
В песочнице разработки Docker-демон недоступен → PostgreSQL 16 запускается бинарниками (`scripts/pg-local.sh`). Для других разработчиков в репо остаётся `docker-compose.yml`.

### D-009 — Шрифты self-host через `@fontsource` · ИИ (06.11)
`next/font/google` скачивает шрифт с Google во время сборки — на билд-серверах в РФ это риск. `@fontsource` берёт файлы из npm, лицензия OFL.

### D-010 — Дизайн-направление A «Посольство» · Капитан (КТ (а), 06.11)
Из трёх вариантов (A «Посольство», B «Кампус», C «Ночная библиотека») выбран A. Тёмная тема сделана в его палитре (глубокий синий + латунь).

### D-011 — Название «Меридиан» · Капитан (КТ (а), 06.11)
Логотип — дуги меридианов и звезда-ориентир (идея международности, без копирования эмблемы вуза).

### D-012 — Смелые идеи: ИИ-помощник, «что, если» по БРС, запись к методисту, командная палитра · Капитан (КТ (а))
Плюс поддерживающие: главный экран «Сегодня», статус «нужно дополнить» как в Госуслугах, справки с QR, языковой паспорт в профиле, день ВУЦ в расписании, PWA, тёмная тема.

### D-013 — `cacheComponents` выключен · ИИ (06.11)
Next 16 по умолчанию включает Cache Components. Кабинет полностью персональный: динамический рендер всех страниц исключает риск отдать закешированные данные одного студента другому. Производительность компенсирована серверными компонентами и ленивой загрузкой палитры.

### D-014 — Drizzle ORM вместо Prisma · ИИ (06.11), отклонение от дефолта ТЗ
Prisma 7 при `migrate` скачивает бинарный schema-engine с binaries.prisma.sh — домен закрыт в песочнице разработки (403). Drizzle — чистый TypeScript, миграции — обычные SQL-файлы в `drizzle/`, нет бинарников → меньше образ и предсказуемая сборка на Amvera. Лицензия Apache-2.0.

### D-015 — Миграции и первичный сид при старте сервера · ИИ (07.11)
`src/instrumentation.ts` → `runStartup()`: применяет миграции, при пустой БД создаёт демо-данные. Родион не запускает команды вручную на хостинге.

### D-016 — Демо-данные «относительно сегодня» и «созревающие» уведомления · ИИ (06.11)
Переносы на ближайшие 10 дней объявлены к моменту сида, дальше — появляются по времени (`created_at ≤ сейчас`). Кабинет остаётся «живым» все три недели проверки без пересоздания.

### D-017 — Офлайн без кэширования личных страниц · ИИ (07.11)
Service worker кэширует только статику и экран `/offline`. Первоначально ИИ кэшировал «Сегодня/Расписание/Успеваемость», но это риск на общем компьютере — убрано.

### D-018 — ИИ-помощник без права действия · ИИ (07.11)
Модель только предлагает «Заполнить заявку» (ссылка на форму с проверенными полями); отправляет студент. Без ключа или при ошибке GigaChat — офлайн-режим: поиск по Положению (TF-IDF) + правила для частых вопросов.

### D-019 — Rate limiting: «логин+IP» / логин / IP, IP от доверенного прокси · ИИ по отчёту аудитора (07.11)
См. находки M-1, M-3 в `PROCESS_LOG.md`, этап 10.

### D-020 — Сертификат НУЦ Минцифры через `NODE_EXTRA_CA_CERTS`, без отключения TLS · ИИ (07.11)
Официальный README пакета gigachat предлагает `rejectUnauthorized: false` — отказались. Сертификат кладётся в `certs/` (ручной шаг капитана).
