## Дополнительно для Claude (Claude Code / Cowork)

### Как ведём работу
- Капитан команды — Родион (не программист). Он ставит задачи, принимает ключевые решения и делает ручные шаги (регистрации, push, проверка с телефона, опрос, озвучка). Пиши ему по-русски, коротко, без жаргона; инструкции для ручных шагов — пошагово.
- Контрольные точки, где нужно «ок» Родиона: (а) концепция и дизайн-направление, (б) перед деплоем, (в) финальная сдача. Между ними — автономно; мелкие решения — сам, с записью в `docs/DECISIONS.md`.
- После каждого этапа: коммит с осмысленным сообщением, запись в `docs/PROCESS_LOG.md`, скриншоты Playwright (360 и 1440) в `docs/screenshots/`.

### Субагенты
Независимые проверки делаем отдельными агентами со свежим контекстом — они не «защищают» свой же код:
| Роль | Когда | Промпт |
|---|---|---|
| Исследователь | до PRD | `docs/prompts/03-research-agent.md` |
| Аудитор безопасности | после ядра и перед деплоем | `docs/prompts/10-security-audit.md` |
| UX/a11y-ревьюер | после разделов | `docs/prompts/11-ux-review.md` |
| QA | после разделов | `docs/prompts/11-qa-e2e.md` |
Каждую постановку задачи сохраняй в `docs/prompts/`, результат и что исправили — в `PROCESS_LOG.md`.

### Ошибки ИИ
Если ИИ (включая тебя) ошибся — не прячь: в `PROCESS_LOG.md` раздел «Ошибки ИИ» — что было, как заметили, как исправили, какое правило добавили, чтобы не повторилось (часто — новая строка в этом файле или в AGENTS.md).

### Окружение
- Локально PostgreSQL 16 можно запустить без Docker: `scripts/pg-local.sh` (initdb в `.pgdata/`).
- Скриншоты и видео — Playwright (Chromium предустановлен), `deviceScaleFactor: 2` для скриншотов в документацию.
